## Why v2 is preferred
v2 links 215 more pairs (71 across Training/Testing), removes
1,223 Training images instead of 1,198, and afterwards no Testing
image has a training or validation partner with correlation ≥ 0.98 within Hamming distance 10. It is preferred because its
split is cleaner, not because of its score.

Accuracy goes from 93.4% to 91.9%. The 19 Testing images whose near-copies v2
removes are classified correctly by both versions, so the drop does not come from them. 79 predictions change
between the versions (38 from correct to wrong, 14 from wrong to correct and 27 from one wrong class to
another; almost all gliomas and meningiomas). The training pool loses only 25 images and the group-wise train/validation
assignment is redrawn, so the difference mainly reflects run-to-run variance of a single training seed, which the confidence
intervals do not capture.

## Changelog

- **LIME run** on the v2 model (no retraining), with the same SLIC superpixels, black baseline and 200 samples as KernelSHAP,
  on the same 100 Testing images: deletion/insertion, foreground share, cascading model randomisation, agreement with the
  other five methods, a target-class check and a seed check ([explainability](explainability.md#lime-added-in-v211);
  [`run_lime.py`](../v2/scripts/run_lime.py)). Results are in new files; no existing metric changed.
- LIME added to the paper, the XAI notebook, this documentation and the READMEs; LIME maps for the eight demo presets.
  Not computed for uploads (more than ~10 s in the browser; [web demo](web_demo.md)).
