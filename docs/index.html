NEURO//SCAN

An EfficientNet-B0 model classifies a 2-D brain MRI slice as glioma, meningioma, pituitary tumour or no tumour, then shows where it looked and why it decided, using only its own outputs. Images never leave your device.

Research and education demo, not a medical device. Do not use it for diagnosis or treatment decisions. Always consult a qualified radiologist or physician.

The rationale appears after a prediction. It is generated from the model's own probabilities, its Grad-CAM map and its measured test-set performance; it contains no medical reasoning.

Sample slices from the test split

Two per class, drawn with a fixed seed. Preset rule: only use test images with no candidate pair at all at Hamming ≤ 10, whatever the correlation; augmented (*-aug-*) files are also excluded. The true label is shown so you can compare. Click one to run it. These also include precomputed Grad-CAM++, Integrated Gradients and KernelSHAP maps.

Sample images: Brain Tumor MRI Dataset by Masoud Nickparvar (Kaggle, CC BY 4.0), itself compiled from figshare, SARTAJ and Br35H. Resized and recompressed for this demo.

Not a medical device. This model was trained on one public, curated Kaggle dataset of 2-D slices without patient identifiers. It has not been clinically validated, can be confidently wrong, and does not detect other pathologies. Outputs are for learning about machine learning only.

About this version (v2). After a team review, v2 uses a stricter duplicate rule (+215 linked pairs; 1,223 instead of 1,198 Training images removed) and a retrained model. Test accuracy is 91.9% (macro-F1 0.919, ROC-AUC 0.987) versus 93.4% (macro-F1 0.933, ROC-AUC 0.989) in v1. The difference mainly reflects run-to-run training variance of a single seed; v2 is preferred because its split is cleaner, not because its score is lower. See the v1 vs v2 table.

Model: EfficientNet-B0 (ImageNet-pretrained, timm), exported to ONNX and run with ONNX Runtime Web. Grad-CAM is computed exactly in the browser from the final feature map and classifier weights; occlusion runs 169 masked forward passes (32-px window, stride 16, as in the paper). © 2026 Rishabh Aryan · MIT License
